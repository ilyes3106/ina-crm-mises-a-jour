# Mises à jour d’INA CRM

Ce dépôt distribue uniquement les mises à jour d’INA CRM envoyées par Ilyes. Chaque publication contient deux fichiers : le paquet chiffré et signé (`.inapkg`), que seules les installations INA CRM peuvent ouvrir, et son annonce signée (`latest.json`).

Il ne contient ni code source ni donnée. Les installations INA CRM vérifient elles-mêmes les nouvelles versions : il n’y a rien à télécharger ici à la main.
